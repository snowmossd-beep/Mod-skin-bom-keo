Hướng dẫn cài đặt

  1. Tạo file mod ở phần trên và tải về. Không đổi tên file.
  2. Thoát hẳn Free Fire, xóa game khỏi danh sách ứng dụng đang chạy.
  3. Mở trình quản lý file và vào thư mục dữ liệu game theo bảng bên dưới.
  4. Sao lưu file gốc cùng tên ra nơi khác.
  5. Chép file mod vào thư mục, chọn thay thế file cùng tên.
  6. Mở lại game và dùng đúng skin bom keo đã chọn.
